# Changelog

## Unreleased

- Add the rest of the 0.7.5 variants, in all five style families and both editions, with recipe fields: a scrolling `DialogBody` named by the dialog title and a Tab stop only while it overflows, a `DialogFooter` that stays visible and stacks below 640px, and Dialog `size` (`sm`, `lg`, `fullscreen`); `AlertDialogMedia` and `AlertDialogConfirmInput`, which keeps the action disabled until the exact text is typed and says why; and Breadcrumb `collapse="auto"`, which folds the middle of a long trail into a "Show N more" menu. Breadcrumb is now a client component, and installing it installs @radix-ui/react-dropdown-menu 2.2.1 in the Radix edition (the Base UI edition adds no dependency). Recipes that use the new fields (`dialog` `size`, `footer` and `scrollingBody`, `alert-dialog` `media` and `confirmText`, `breadcrumb` `collapse`) need CLI 0.7.5. Liquid glass remains experimental.
- The website editors use these: the top bar's trail is a collapsing Breadcrumb; the Get code dialog is a large Dialog with a scrolling body and its Copy command in the footer; the preset ID and revision dialog is a Dialog; the family change and token reset confirmations are Alert Dialogs with media, keeping the list of changed values; and replacing saved recovery data asks with a destructive Alert Dialog instead of the browser's confirm.
- Add the first 0.7.5 variants, in all five style families and both editions, with recipe fields: `CheckboxOption`, a checkbox with a title and a description as a row or a card, named by its title and described by its description, that toggles from anywhere on it; a small Switch (`size="sm"`) with a hit area of at least 24 × 24 px; Progress `size` and `tone`, and `ProgressLabel` and `ProgressValue`, which name the bar and give it the readout as its value text; and `PopoverArrow`. Leaving them out renders what earlier releases render. Recipes that use the new fields (`checkbox` `option` and `description`, `switch` `size`, `progress` `size`, `tone`, `showLabel` and `showValue`, `popover` `arrow`) need CLI 0.7.5. Liquid glass remains experimental.
- Add Number Input and Color Picker in all five style families, with Radix and Base UI editions, recipe editors, source exports and preview scenes. Number Input is a text field with `role="spinbutton"`, steppers, a spoken unit and keyboard stepping; a half-typed value stays in the field and is reported as invalid instead of being cleared, and an editor can hand back its stored text with `text`. Color Picker is a swatch button and a text field with a popover: a saturation and brightness area announced as a 2D slider, a hue slider, OKLCH, Hex and RGB formats, swatches, a WCAG 2 contrast readout that states its level in text, and an eyedropper where the browser has the EyeDropper API. `ColorPickerPair` groups the light and dark pickers of a token. A typed OKLCH colour outside sRGB is kept as typed. Color Picker uses its edition's Popover and Slider primitives directly (@radix-ui/react-popover 1.3.1 and @radix-ui/react-slider 1.6.1 in the Radix edition) and installs no other catalog component; the Base UI edition adds no dependency. Installing them needs CLI 0.7.5. Liquid glass remains experimental.
- The website's preset and component editors use the compiled Number Input and Color Picker: each preset token's light and dark fields are a Color Picker Pair with the colour schemes as swatches and contrast against its foreground; the component editor's colour roles and part colours are Color Pickers; and the inspector's number fields, the shadow offsets and the integer recipe properties are Number Inputs. Native `<input type="color">` and `type="number"` controls are gone from the editors. The editor routes load more JavaScript: `/editor/preset` +42.1 kB and `/editor/component/button` +29.9 kB (gzip), and `/components` +24.7 kB, mostly the catalog source the routes ship; this was reviewed and accepted.
- Add Code Block in all five style families, with Radix and Base UI editions, a recipe editor, source exports and preview scenes. `CodeBlock` shows a file with a title, line numbers and Copy; `CodeBlockCommand` shows a command with one tab per package manager (`pnpm dlx`, `npx`, `yarn dlx` and `bunx`, which `runners` can replace); the parts and `CodeBlockRoot` are exported for custom layouts, and `highlightCode` for your own markup. Its highlighter covers TSX, CSS, JSON and shell with no dependency, and another highlighter's output can be passed as children. The surface is dark in both modes; every token colour reaches 4.5:1 on it and line numbers 3:1. The code is a named, scrollable region, line numbers are neither read nor copied, and Copy announces "Copied" or "Copy failed". The Radix edition uses @radix-ui/react-tabs 1.2.1; the Base UI edition adds no dependency. Installing it needs CLI 0.7.5. Liquid glass remains experimental.
- The website's docs, component pages, playground, editors' artifact views and Get code dialog use the compiled Code Block in place of the site's own code block, command tabs and highlighter; the Get code dialog's package-manager buttons are now the tabs of a Code Block Command. Of the seven measured routes, `/editor/component/button` loads 10.9 kB more JavaScript (gzip) and `/components/accordion` 10.4 kB, over the 10 kB limit, mostly the Code Block template source the catalog routes ship. The maintainer accepted both overages; they are recorded in `docs/evidence/code-block-075.md`.
- Add Toggle, Collapsible, Scroll Area, Button Group and Item in all five style families, with Radix and Base UI editions, recipe editors, source exports and preview scenes. Toggle is a two-state button with `aria-pressed`; Collapsible hides its content from the Tab order while closed; Scroll Area has a styled scrollbar and its viewport is a keyboard stop only while its content overflows; Button Group joins Buttons, Inputs and Select triggers, and a split button is a Button plus a Dropdown Menu trigger around an icon Button; Item is a row of media, text and actions, whose link and actions are siblings inside an Item Group. The Radix editions use @radix-ui/react-toggle 1.2.1, @radix-ui/react-collapsible 1.2.1 and @radix-ui/react-scroll-area 1.4.0; the Base UI editions add no dependency. Installing them needs CLI 0.7.5. Liquid glass remains experimental.
- Draw the family scrollbar on the Command, Combobox, Select and Sheet lists. The rules are in each component's stylesheet, so a project that installed one earlier gets them by deleting that stylesheet (`command.css`, `combobox.css`, `select.css` or `sheet.css`) and running `add` for the component again: `add` alone reports a `FILE_CONFLICT` for the recorded file, and `theme add` does not rewrite component stylesheets. See [Scroll Area](docs/components/scroll-area.md#existing-lists).
- The website editors and docs use the catalog components, compiled at build time: the site theme toggle is a Toggle; the disclosures in the glass panel, the preset export panel, the preset confirmation and the docs mobile components sidebar are Collapsibles instead of `<details>`; the editor rails and panels, the review drawer, the Get code dialog body and the artifact tabs are Scroll Areas; and Undo and Redo are a Button Group named "History". The site's generated `cn` is now clsx only, without tailwind-merge. Measured for the primitives, before the editor inputs and Code Block, the seven measured routes loaded at most 8.9 kB more JavaScript (gzip), on `/editor/preset`, within the 10 kB limit.
- The specimen audit judges overflow on each axis, so a scrolling area whose content is taller than its box is no longer reported as cut off.
