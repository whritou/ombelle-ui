# Primitives (0.7.5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Toggle, Collapsible, Scroll Area, Button Group and Item to the catalog in both editions and all five families, with recipes; give the shipped lists family scrollbars; then use the new components in the website editors and docs.

**Architecture:**
- **Catalog:** follow the 0.7.3 form controls (`docs/superpowers/plans/2026-11-10-form-controls.md`) end to end: contract ids, schema branches and appearance parts; self-contained templates and per-family styles; compiler specimens and install gating; preview and website registration; docs. Templates never import other catalog components; a recipe specimen renders native elements marked with `data-<component>-…` attributes, as the Empty and Field specimens do.
- **Website:** `scripts/generate-www-ui.ts` compiles the components the site uses at build time into `apps/www/src/generated/ui/`; nothing compiles when a page loads.

**Tech Stack:**
- TypeScript ES modules and React 19.
- Radix: `@radix-ui/react-toggle` 1.2.1, `@radix-ui/react-collapsible` 1.2.1, `@radix-ui/react-scroll-area` 1.4.0.
- Base UI 1.9.0: `Toggle`, `Collapsible`, `ScrollArea` (all present in the installed package).
- Next.js 16 for `apps/www`. Vitest and Playwright.

**Spec:** `docs/superpowers/specs/2026-11-12-primitives-075-design.md`

## Review Focus

- **A Scroll Area whose content does not overflow.** A focusable viewport that cannot scroll is an empty Tab stop. Expected: the viewport takes `tabIndex={0}` only while its content overflows in either axis (checked with a ResizeObserver on the viewport and its content), and loses it when the content shrinks. Task 4 pins it in SSR (no `tabindex` before measurement) and Task 9 in the browser.
- **Closed Collapsible content with focusable children.** Tab must skip links and buttons inside closed content in both editions, and reach them once open. Task 9 pins it.
- **An Item link inside an `ItemGroup`.** The link keeps its `link` role and its actions are not inside it. Expected: `role="listitem"` sits on the group's wrapper `div`, the `a` stays a link, and `ItemActions` is a sibling of the link. Task 6 pins it in SSR.
- **A Button Group with one child, or with a disabled child.** One child keeps all four rounded corners; a disabled child keeps the joined border; the focused child's ring is drawn above its neighbours. Task 9 pins it with computed styles.
- **The site theme toggle on first paint.** The page's theme comes from `themeInitScript` before React runs; the compiled Toggle must not flash or mismatch. Expected: no hydration warning, and `aria-pressed` matches the `dark` class after mount. Task 10 pins it in the www unit test and the existing theme e2e.
